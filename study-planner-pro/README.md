> A professional, full-featured web application for students to manage subjects, assignments, and deadlines efficiently. Built with PHP, MySQL, and a modern UI/UX.

## ✨ Features

- 🔐 **Secure Authentication** – Registration/Login with hashed passwords.
- 📊 **Interactive Dashboard** – Real-time stats, progress bar, and upcoming deadlines.
- 📚 **Subject Management** – Full CRUD (Add, Edit, Delete).
- 📝 **Task Management** – Full CRUD with status (Pending/In Progress/Completed).
- 👤 **Profile Management** – Update name and password.
- 🎨 **Modern UI** – Gradient design, glassmorphism cards, responsive.
- ⚡ **Flash Messages** – User-friendly success/error notifications.

## 🛠️ Tech Stack

- **Backend**: PHP 7.4+ (PDO)
- **Database**: MySQL 5.7+
- **Frontend**: HTML5, CSS3 (Flexbox/Grid), Vanilla JS
- **Server**: Apache (XAMPP/WAMP/LAMP)
