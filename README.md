# 📚 StudyHub Pro

> A modern, full-featured student study planner web application.

---

## 🚀 About

StudyHub Pro helps students manage their subjects, tasks, and deadlines efficiently. Built with PHP, MySQL, HTML, CSS, and JavaScript.

---

## ✨ Features

- 🔐 Secure Login & Registration
- 📊 Interactive Dashboard with stats & charts
- 📚 Subject Management (Add, Edit, Delete)
- 📝 Task Management with Priority & Status
- 👤 Profile Management
- 🌙 Dark/Light Mode
- 🔔 Real-time Notifications
- 📱 Fully Responsive

---

## 🛠️ Tech Stack

- **PHP 7.4+** (PDO)
- **MySQL 5.7+**
- **HTML5, CSS3, JavaScript (ES6)**
- **Font Awesome** Icons
- **Google Fonts** (Inter)
